### 로그인 페이지 규칙 및 워크플로우

#### 레이아웃 구조

**왼쪽 섹션** (`AuthLeftComponent`)
- 검은색(#000)에서 진한 빨간색(#311917)으로의 선형 그라데이션 배경
- 상단: 모아티켓 로고 (30px)
- 중간: 주요 텍스트
  - 제목: "무대의 첫 줄 가장 가까운 자리에서" (48px, 800 weight)
  - 부제: "콘서트, 뮤지컬, 연극, 클래식, 스포츠까지. 지금 MOA TICKET에서 예매하세요." (22px, 300 weight)
- 하단: 통계 정보 (보더 없는 3단 레이아웃)
  - 누적 예매: 1,200만+
  - 공연/이벤트: 8,400+
  - 앱 평점: 4.9
- 맨 아래: "2026 MOA TICKET. 본 화면은 예시 화면입니다." (14px)
- 모든 텍스트는 흰색(#fff)

**오른쪽 섹션** (`LoginRightComponent`)
- 흰색(#fff) 배경
- 상단 (모바일에서만): 로고 (30px)
- 제목: "다시 오신 걸 환영해요" (32px, 800 weight, 데스크톱) / (24px, 모바일)
- 부제: "로그인하고 예매를 이어가세요." (16px, 400 weight)
- 입력 필드:
  - 이메일 (email 타입)
  - 비밀번호 (password 타입)
- 하단 옵션:
  - 왼쪽: "아이디 저장" 체크박스
  - 오른쪽: "비밀번호 찾기" 버튼
- 로그인 버튼 (빨강 #ed4543)
- 소셜 로그인:
  - "또는" 구분선
  - 카카오톡 로그인 버튼
  - 네이버 로그인 버튼
- 하단 링크: "아직 회원이 아니신가요?" + "회원가입" 링크

#### 반응형 설계

**데스크톱 (1080px 이상)**
- 왼쪽 섹션: 50% 너비, flex로 표시
- 오른쪽 섹션: 50% 너비
- 전체: flex 레이아웃으로 나란히 배치

**모바일 (1080px 미만)**
- 왼쪽 섹션: hidden
- 오른쪽 섹션: 100% 너비, 가운데 정렬
- 로고: 상단에 표시
- 패딩: 20px (sm 이상 45px)

#### 상태 관리
- `useState`로 "아이디 저장" 체크박스 상태 관리

#### 컴포넌트 구조
- 왼쪽 레이아웃은 회원가입 페이지에서도 재사용하는 `AuthLeftComponent`로 구성
- 오른쪽은 `LoginRightComponent`로 독립적으로 구성
