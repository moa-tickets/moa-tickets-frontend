### 회원가입 페이지 규칙 및 워크플로우

#### 레이아웃 구조

**왼쪽 섹션** (`AuthLeftComponent`)
- 로그인 페이지의 왼쪽 섹션과 동일
- 검은색(#000)에서 진한 빨간색(#311917)으로의 선형 그라데이션 배경
- 로고, 주요 텍스트, 통계 정보 동일 구성

**오른쪽 섹션** (`SignupRightComponent`)
- 흰색(#fff) 배경
- 상단 (모바일에서만): 로고 (30px)
- 제목: "모아티켓 시작하기" (32px, 800 weight)
- 부제: "멋있는 공연을 예매하려면 시작하세요." (14px, 400 weight)
- 입력 필드 (순서대로):
  1. 이름 (text 타입, placeholder: "홍길동")
  2. 이메일 (email 타입, placeholder: "onyu.kim@example.com")
  3. 비밀번호 (password 타입, placeholder: "••••••••")
  4. 비밀번호 확인 (password 타입, placeholder: "••••••••")
  5. 휴대폰 번호 (tel 타입, placeholder: "010-0000-0000")
     - 입력 필드와 "인증요청" 버튼을 한 줄에 flex 레이아웃으로 배치
     - 버튼: 빨강 #ed4543, hover시 더 어두운 빨강
  6. 인증 코드 (text 타입, placeholder: "000000")
  7. 닉네임 (text 타입, placeholder: "모아팬")
- 체크박스: "만 14세 이상이며, 이용약관 및 개인정보 처리정책에 동의합니다."
  - 개인정보 처리정책 텍스트는 빨강(#ed4543) 색상
- 제출 버튼: "가입하고 시작하기" (빨강 #ed4543)
- 소셜 가입:
  - "또는" 구분선
  - 카카오톡으로 로그인 버튼
  - 네이버로 로그인 버튼
- 하단 링크: "이미 계정이 있으신가요?" + "로그인" 링크

#### 반응형 설계

**데스크톱 (1080px 이상)**
- 왼쪽 섹션: 50% 너비, flex로 표시
- 오른쪽 섹션: 50% 너비
- 패딩: 45px (좌우), 40px (상하)

**모바일 (1080px 미만)**
- 왼쪽 섹션: hidden
- 오른쪽 섹션: 100% 너비, 가운데 정렬
- 로고: 상단에 표시
- 패딩: 20px (기본), 45px (sm 이상)

#### 상태 관리
- `useState`로 이용약관 동의 체크박스 상태 관리

#### 컴포넌트 구조
- 왼쪽 레이아웃은 로그인 페이지와 공유하는 `AuthLeftComponent` 재사용
- 오른쪽은 `SignupRightComponent`로 독립적으로 구성
